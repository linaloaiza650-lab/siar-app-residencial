# SIAR S.A.S. — Sistema Integral de Administración Residencial

## Descripción
SIAR S.A.S. es un proyecto académico de desarrollo de software que busca mejorar la comunicación entre residentes, personal de seguridad y administración de unidades residenciales de Medellín, Antioquia.

El prototipo permite consultar comunicados de ejemplo y registrar solicitudes de mantenimiento, convivencia, seguridad, reservas de zonas comunes y otros asuntos.

## Objetivo general
Diseñar y desarrollar una aplicación que facilite la comunicación y la gestión de información en las unidades residenciales mediante una solución tecnológica organizada y fácil de utilizar.

## Funcionalidades del prototipo
- Consulta de comunicados de ejemplo.
- Formulario para registrar solicitudes.
- Visualización de solicitudes registradas en el navegador.
- Contadores de comunicados y solicitudes.
- Diseño adaptable a computadores y celulares.

## Tecnologías
- HTML5: estructura de las páginas.
- CSS3: estilos y diseño adaptable.
- JavaScript: interacciones y validación del formulario.
- LocalStorage: almacenamiento local de las solicitudes de demostración.

## Requisitos
Un navegador actualizado, como Google Chrome, Microsoft Edge o Firefox. No requiere instalación de servidor para ejecutar la versión inicial.

## Instalación y ejecución
1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Abre `index.html` en un navegador.
4. Prueba el formulario con datos ficticios.

También puedes abrir la carpeta en Visual Studio Code y usar la extensión Live Server si está instalada.

## Limitaciones
Esta versión es un prototipo académico. Los comunicados son ejemplos; las solicitudes se guardan solamente en el navegador del equipo y no se comparten con otros usuarios. No incluye cuentas, autenticación, servidor ni base de datos central.
